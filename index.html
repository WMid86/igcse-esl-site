Extensive Reading Project Tracker

This website supports a shared Google Sheets workflow. Student reading entries and teacher implementation checks flow into one central spreadsheet so staff can work from the same data.

Use the student form to log reading. Use the teacher dashboard to review shared entries, export filtered data, and monitor implementation quality. Use the implementation form to record whether ER routines are actually happening in class.
