Extensive Reading Project Tracker

This website now supports a shared Google Sheets workflow. Student reading entries and teacher implementation checks are designed to flow into one central spreadsheet so all staff can work from the same data rather than isolated browser storage.

Use the student form to log reading. Use the teacher dashboard to review shared entries, export filtered data, and monitor implementation. Use the implementation form to record whether ER routines are actually happening in class.
